# Local Panel Independent High Level Alarm - PLC Program 
Independent High-Level Alarm (IHLA) Local Panel is a safety device installed on fuel storage tanks to monitor fuel levels and provide alarms when the fuel reaches a critical level. The IHLA system relies on a Programmable Logic Controller (PLC), which requires a program to control and execute its operations. The PLC program was developed using the Ladder Diagram.

## A. Software Tools
CX-One was used to develop the PLC program using the Ladder Diagram programming language.
